# MediSense 실제 사용자 화면 목록

- 분석 기준일: 2026-09-02
- 분석 대상: React Router, `frontend/src/features`, 공통 Layout, Frontend API Client, FastAPI Router
- 작성 목적: 최종 화면 정의서에 사용할 실제 독립 페이지와 주요 관리자 탭 식별

## 1. 화면 식별 기준

- React Router에 등록된 독립 경로는 하나의 화면으로 본다.
- `/admin` 내부의 `RAG 등록`, `LLM`, `성능 지표`는 업무 목적과 UI가 명확히 분리된 주요 탭이므로 각각 화면 ID를 부여한다.
- 모달, 드롭다운, 파일 미리보기, 사이드바, 테마 전환 등은 별도 화면으로 분리하지 않는다.
- Embedding 생성, Vector DB 저장, RAG 검색 Pipeline처럼 사용자 UI가 없는 내부 처리는 별도 화면으로 만들지 않는다.
- 동일 Component를 재사용하더라도 접근 경로와 사용자 유형이 다른 경우에는 화면 정의서 검토를 위해 별도 행으로 표시한다.
- Router에 등록되어 있어도 제목만 출력하는 페이지는 `자리표시자`로 표시한다.

## 3. 화면 구조와 접근 제어 참고사항

### 공통 Layout

- 실제 Router는 `MainLayout`을 사용한다.
- 일반 화면은 상담 이력 Sidebar, 관리자 이동 메뉴, 테마 전환, 본문, 문서 미리보기 Panel을 공유한다.
- `/admin`, `/dashboard`에서는 상담 Sidebar 대신 로고만 있는 관리자용 축소 Rail을 표시한다.
- `frontend/src/components/AppLayout.tsx`에는 문서·OCR·검색·평가 메뉴가 정의되어 있지만 현재 `router.tsx`에서 사용하지 않는다. 따라서 이 Layout의 메뉴를 실제 Navigation으로 간주하면 안 된다.

### 접근 제어

- `/mypage`와 `/my`는 `RequireAuth`로 보호되는 같은 화면이며 `/my`는 별칭 Route다.
- `/admin`과 `/dashboard`는 `RequireAdmin`으로 보호된다. 비로그인 사용자는 로그인 화면으로, 일반 회원은 상담 시작 화면으로 이동한다.
- `/`, `/chat/:conversationId`, `/search`는 게스트 Session을 발급받아 비회원도 사용할 수 있다.
- `/evaluation`은 현재 React Router에서 인증 Guard가 없다. 관리자 성능 지표와 같은 Component를 재사용하므로 최종 화면 정의서에서는 공개 화면 유지 여부를 결정할 필요가 있다.
- `/document`, `/ocr`, `/search`, `/evaluation`은 현재 사용하는 `MainLayout` Sidebar에 직접 이동 메뉴가 없다. `/search`와 `/evaluation`은 주소로 접근하면 실제 기능이 동작하지만 공식 사용자 동선은 별도로 정해야 한다.
- 별도의 Not Found(404) 화면 Route는 정의되어 있지 않다.

## 4. 화면 정의서 포함 권장 화면

다음은 실제 서비스의 핵심 사용자 흐름 또는 관리자 업무를 담당하므로 화면 정의서에 포함하는 것이 좋다.

| 구분 | 권장 화면 ID | 이유 |
|---|---|---|
| 핵심 상담 | USR-001, USR-002 | 서비스의 시작점과 실제 AI 상담이 이루어지는 핵심 화면 |
| 회원·계정 | AUTH-001~AUTH-005, USR-003 | 독립 Route와 API를 가진 완성된 인증·계정 관리 화면 |
| RAG 검색 | USR-004 | 실제 검색 UI와 API가 구현된 독립 화면. 다만 Navigation 반영 여부 확인 필요 |
| 관리자 AI 운영 | ADM-001~ADM-003 | RAG 등록, LLM 비교, 성능평가라는 서로 다른 핵심 관리자 업무 |
| 관리자 모니터링 | ADM-004 | 서비스 운영 KPI와 통계를 확인하는 독립 관리자 화면 |

## 6. 권장 사용자 화면 흐름

```text
게스트/회원
AI 상담 시작 → 상담 채팅 → 대화 이력 재진입
                 ├─ RAG 근거 문서 검색(선택)
                 └─ 로그인 → 회원가입/인증 또는 마이페이지

관리자
로그인 → 관리자 RAG 자료 등록 / LLM 응답 비교 / 성능 지표 → 운영 대시보드
```
