## 2. 결론

- 직접 담당 기능군: 6개
- 공동 작업 기능군: 4개
- 타 팀원 담당 또는 최승준 범위에서 제외할 기능군: 5개
- 실험/분석 기능군: 2개
- 폐기·교체·현재 미사용 기능군: 3개
- 단위테스트 후보 모듈: 6개
- 예상 테스트 후보: 42건
- 사용자 확인 필요 사항: 3개

핵심 판단은 다음과 같다.

1. 최승준의 현재 유효한 핵심 범위는 Admin OCR 흐름, OCR Job, 웹 URL OCR,
   OCR 결과의 Embedding/저장 오케스트레이션, Admin LLM Facade와 공통 LLM Application,
   Admin Frontend 상태 관리다.
2. 현재 `ai/ocr`은 최승준이 통합한 공통 Core이지만, 기존 팀원 코드 이식과 이후
   텍스트/ZIP 확장이 섞여 있어 전체를 단독 담당으로 볼 수 없다.
3. Jina v4·Medical BGE-M3 이중 Embedding, RRF 검색, Vast.ai Remote HTTP Provider,
   대용량 R2 업로드는 다른 팀원 구현 비중이 명확하다. 최승준 테스트 범위는 이 구현체
   내부가 아니라 자신이 만든 Adapter/오케스트레이션 경계로 제한해야 한다.
4. 초기 Mock OCR/Vector 저장과 Gemini Provider는 현재 실행 경로에서 교체되었다.
   과거 기여로 기록하되 현재 서비스 단위테스트 대상에서는 제외한다.
5. RAG 프롬프트 평가 스크립트와 Generation Override 분석은 서비스 기능이 아니라
   실험·분석 산출물이다.

## 5. 현재 실제 실행 경계

### 5.1 Admin 파일 OCR

```text
Admin UI
→ useOcrTest.analyze()
→ apiAdminAiService.analyzeDocument()
→ POST /api/admin/ocr/jobs
→ OcrJobManager.create_job()
→ OcrWorkflowService.process_document()
→ ai.ocr.pipeline.analyze_document()
→ ocr_chunk_service.create_chunks()
→ OcrDocumentResponse
→ GET /api/admin/ocr/jobs/{job_id} Polling
```

### 5.2 Admin 웹 URL OCR

```text
Admin URL 입력
→ POST /api/admin/ocr/url-jobs
→ OcrJobManager.create_url_job()
→ WebOcrWorkflowService.process_url()
→ URL/DNS/Redirect/용량 검증
→ HTML 본문·이미지 후보 추출
→ 내부 이미지 OCR
→ Chunk 생성
→ 기존 Admin OCR Response 계약
```

### 5.3 OCR 결과 저장

```text
POST /api/admin/ocr/vector-save
→ save_ocr_result_with_embeddings()
→ 완료 Job/Chunk 검증
→ 현재 Jina/BGE Embedder 호출
→ Provider 수·Vector 개수·1024차원 재검증
→ DocumentRepository.save_with_chunks()
→ 문서·Chunk·Provider별 Vector 저장
```

이 흐름에서 최승준 후보는 완료 Job 검증, Embedder/Repository 호출 순서, 저장 전 계약
검증과 응답 조립이다. Jina/BGE HTTP 구현과 현 Repository 내부 전체를 단독 범위로 잡지 않는다.

### 5.4 Admin LLM

```text
Admin UI
→ useLlmComparison
→ GET /api/admin/llm/models 또는 POST /api/admin/llm/run
→ admin_llm Facade
→ ai.llm.LlmApplicationService
→ llm_runtime의 RemoteHttpLlmProvider
→ Vast.ai
```

최승준 후보는 UI 상태 전이, Admin DTO 변환, 모델/Provider Registry 해석,
Application 실행 결과 조립과 비교 요청의 부분 실패 격리다. 실제 Remote HTTP 전송과
Vast.ai 서버 내부는 제외한다.
